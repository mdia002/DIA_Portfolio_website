# Images des projets

Dépose ici tes captures d'écran et schémas de workflow. Les noms de fichiers
doivent correspondre exactement à ceux référencés dans `data/projects.json`
(champs `workflowImage` et `screenshots[].src`).

Recommandations :
- Schémas de workflow : export PNG depuis Excalidraw, draw.io ou un simple
  schéma annoté, format large (1600px de large minimum), fond clair.
- Captures d'écran d'interface : annoter les boutons/étapes clés (numéros,
  flèches) directement sur l'image pour montrer où cliquer.
- Poids conseillé : < 500 Ko par image (compresser avec squoosh.app si besoin).

Tant qu'une image n'est pas ajoutée, le site affiche automatiquement un
espace réservé — rien ne casse.
